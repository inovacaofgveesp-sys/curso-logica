Por que demonstrações importam — e como dominá-las

Todo teorema de matemática tem a forma P → Q. Provar um teorema significa mostrar, com rigor, que sempre que P vale, Q também vale. Este módulo ensina as quatro principais estratégias para fazer isso.

Ao final, você conseguirá ler — e escrever — demonstrações dos tipos encontrados em Álgebra Linear e Matemática II.

Matemática não é apenas calcular: é argumentar com precisão. Cada afirmação precisa de justificativa, e cada justificativa precisa partir de verdades já estabelecidas — até chegarmos aos axiomas, as verdades primitivas do sistema.

As quatro técnicas deste módulo cobrem praticamente todos os casos: prova direta (deduz Q a partir de P), contraposição (prova ¬P a partir de ¬Q), contradição (assume ¬Q e chega num absurdo) e indução (prova para todos os naturais de uma vez).

O módulo conecta diretamente ao Módulo 1: a contraposição é a equivalência lógica P→Q ≡ ¬Q→¬P que você já conhece. A contradição parte da tabela verdade de P→Q. A indução usa quantificadores ∀ e →.

Aula 01

O que é uma Prova Matemática?

Axiomas, modus ponens e a estrutura de qualquer demonstração

Vídeo Aula 01 — em breve
~8 min
Motivação e estrutura de provas matemáticasAULA 01
Baixar slides desta aula (PDF)

Provar algo em matemática significa construir uma cadeia de raciocínio que parte de verdades já estabelecidas e chega à afirmação que queremos mostrar. Não basta "verificar casos" nem "parecer óbvio" — a prova precisa ser válida para todos os casos cobertos pelo enunciado.

Toda essa cadeia precisa ter um começo. Esse começo são os axiomas: verdades primitivas que são aceitas sem prova, como os axiomas de Peano para os naturais ou os axiomas da teoria dos conjuntos. A partir deles, toda a matemática é construída.

A ferramenta central é o modus ponens: se P → Q é verdadeiro e P é verdadeiro, então Q é verdadeiro. É isso que permite encadear implicações.

Modus Ponens (MP):

((P → Q) ∧ P) → Q

Uma prova direta é uma cadeia de MP:

P — hipótese
P → P₁ — implicação válida
P₁ → P₂ — implicação válida
⋮
Pₙ → Q — implicação válida
∴ Q — por modus ponens repetido
Tipos de prova
Prova direta · Contraposição · Contradição · Indução — todas são formas de construir essa cadeia. A diferença está em por onde começar e o que assumir.
Referência Bibliográfica
Book of Proof (Hammack): Cap. 4, introdução (pp. 84–86) — O que é uma prova direta.
Verificação rápida — 1
AProvar um teorema significa verificar que ele vale para muitos casos específicos.
BProvar um teorema significa construir uma cadeia lógica que garanta sua validade em todos os casos cobertos pelo enunciado.
CProvar um teorema significa encontrar um exemplo que o ilustre bem.
Verificação rápida — 2: o que são axiomas?
AAxiomas são teoremas muito importantes que precisam de prova longa.
BAxiomas são verdades primitivas aceitas sem prova, das quais todo o resto é deduzido.
CAxiomas são definições de termos matemáticos.
Verificação rápida — 3: modus ponens diz que:
ASe P → Q e Q são verdadeiros, então P é verdadeiro.
BSe P → Q e P são verdadeiros, então Q é verdadeiro.
CSe P → Q é verdadeiro, então P e Q são ambos verdadeiros.
Aula 02

Prova Direta

Assumir P e deduzir Q passo a passo

Vídeo Aula 02 — em breve
~8 min
Prova Direta — estrutura e exemplosAULA 02
Baixar slides desta aula (PDF)

A prova direta é a técnica mais intuitiva: assume-se que P é verdadeiro e, por uma sequência de deduções lógicas, mostra-se que Q também deve ser verdadeiro.

Por que isso basta? Porque pela tabela verdade de P → Q, o único caso em que a implicação é falsa é quando P é verdadeiro e Q é falso. Se garantirmos que P verdadeiro implica Q verdadeiro, a implicação é sempre verdadeira.

Exemplo econômico: para provar "se um mercado é perfeitamente competitivo (P), então o lucro econômico de longo prazo é zero (Q)", assume-se P e deduz-se Q via entrada de firmas e competição de preços.

Estrutura da prova direta:

Teorema: P → Q
Prova: Assuma P.
[deduções intermediárias P → P₁ → P₂ → … → Q]
Portanto Q. ∎

Exemplo — Desigualdade AM-GM:

Teorema: Para x, y ∈ ℝ positivos, √(xy) ≤ (x+y)/2
Prova: Assuma x > 0 e y > 0. Então:
0 ≤ (√x − √y)² = x + y − 2√(xy)
∴ 2√(xy) ≤ x + y
∴ √(xy) ≤ (x+y)/2 ∎

Exemplo — Múltiplos de 4:

Teorema: Todo múltiplo de 4 pode ser escrito como 1 + (−1)ⁿ(2n−1) para algum n ∈ ℕ
Prova: Seja k = 4a para algum a ∈ ℤ. Analisamos 3 casos:
• a = 0: tome n = 1. Então 1 + (−1)¹(2·1−1) = 0 = k ✓
• a > 0: tome n = 2a (par). Então 1 + (2n−1) = 2n = 4a = k ✓
• a < 0: tome n = 1−2a (ímpar). Então 1 − (2n−1) = 4a = k ✓ ∎
Referência Bibliográfica
Book of Proof (Hammack): Cap. 4 (pp. 84–100) — Prova direta.
Verificação rápida — 1
ANa prova direta, assume-se P verdadeiro e deduz-se que Q também é verdadeiro.
BNa prova direta, assume-se Q falso e deduz-se que P também é falso.
CNa prova direta, verifica-se P → Q para vários valores específicos.
Verificação rápida — 2
AA prova direta funciona porque P → Q é sempre verdadeira.
BA prova direta funciona porque P → Q só é falsa quando P é verdadeiro e Q é falso — e a prova direta descarta exatamente esse caso.
CA prova direta funciona porque P → Q é falsa quando P é falso.
Verificação rápida — 3: na prova da AM-GM, qual é a hipótese P?
A√(xy) ≤ (x+y)/2
Bx > 0 e y > 0 (x e y são reais positivos)
C(√x − √y)² ≥ 0
Aula 03

Prova por Contraposição

Uma prova direta da forma equivalente ¬Q → ¬P

Vídeo Aula 03 — em breve
~8 min
Contraposição — quando P é difícil, trabalhe com ¬QAULA 03
Baixar slides desta aula (PDF)

Do Módulo 1, sabemos que P → Q é logicamente equivalente a ¬Q → ¬P. A prova por contraposição explora exatamente isso: em vez de provar P → Q diretamente, provamos sua contraposição.

Quando usar? Quando a hipótese P é complicada de trabalhar, mas a negação ¬Q é mais manejável. O exemplo clássico: provar "se x² − 6x + 5 é par, então x é ímpar" diretamente exigiria isolar x de uma expressão quadrática — difícil. Pela contraposição, assumimos "x é par" (¬Q) e mostramos que "x² − 6x + 5 é ímpar" (¬P) — muito mais simples.

Atenção: contraposição não é o mesmo que contradição. Na contraposição, provamos ¬Q → ¬P diretamente, sem assumir nenhum absurdo.

Por que é válida:

P → Q ≡ ¬P ∨ Q ≡ Q ∨ ¬P ≡ ¬Q → ¬P

Estrutura:

Teorema: P → Q
Prova (contraposição): Assuma ¬Q.
[deduções: ¬Q → … → ¬P]
Portanto ¬P. Logo P → Q. ∎

Exemplo — x² − 6x + 5:

Teorema: Se x² − 6x + 5 é par, então x é ímpar.
Prova (contraposição): Assuma ¬Q: x é par, logo x = 2a para algum a ∈ ℤ.
x² − 6x + 5 = 4a² − 12a + 5 = 4a² − 12a + 4 + 1 = 2(2a²−6a+2) + 1
Portanto x² − 6x + 5 é ímpar (¬P). ∎

Exemplo — De Morgan na contraposição:

Teorema: Se 5 não é divisível por xy, então 5 não é divisível por x nem por y.
Prova (contraposição): Assuma ¬Q: pela Lei de De Morgan,
"5 é divisível por x" OU "5 é divisível por y".
Em ambos os casos: xy = 5(ay) ou xy = 5(ax), logo 5 | xy (¬P). ∎
Referência Bibliográfica
Book of Proof (Hammack): Cap. 5 (pp. 106–116) — Prova por contraposição.
Verificação rápida — 1
AA prova por contraposição assume P falso e mostra Q falso.
BA prova por contraposição assume ¬Q e mostra ¬P — é uma prova direta de ¬Q → ¬P.
CA prova por contraposição assume P e ¬Q e chega a uma contradição.
Verificação rápida — 2: quando preferir contraposição à prova direta?
ASempre — a contraposição é mais rigorosa que a prova direta.
BQuando ¬Q é mais fácil de trabalhar do que P, ou quando P é difícil de manipular diretamente.
CQuando Q é verdadeiro e P é falso.
Verificação rápida — 3
AContraposição e contradição são a mesma técnica com nomes diferentes.
BNa contraposição, prova-se ¬Q → ¬P diretamente. Na contradição, assume-se P ∧ ¬Q e busca-se um absurdo — são técnicas diferentes.
CContraposição prova Q → P, não ¬Q → ¬P.
Aula 04

Prova por Contradição

Assumir o absurdo — e por que isso nem sempre é a melhor escolha

Vídeo Aula 04 — em breve
~12 min
Contradição — reductio ad absurdum e diferença com contraposiçãoAULA 04
Baixar slides desta aula (PDF)

A prova por contradição (ou reductio ad absurdum) funciona assim: assumimos que o que queremos provar é falso e mostramos que isso leva a uma contradição — uma situação logicamente impossível. Como um sistema lógico consistente não admite contradições, a hipótese de que a afirmação era falsa deve ser rejeitada.

Força: ao contrário das outras técnicas, a contradição serve para provar proposições não condicionais também — como "√2 é irracional" ou "existem infinitos primos". Nesses casos, não há P → Q explícito: basta assumir o contrário e chegar no absurdo.

Fraqueza: para proposições condicionais P → Q, a contradição frequentemente acaba sendo apenas uma contraposição disfarçada e mais complicada. Se você assumiu P ∧ ¬Q e sua contradição veio apenas de ¬Q, você na verdade fez uma contraposição — sem perceber. Nesse caso, a contraposição é preferível: mais simples e mais informativa.

Estrutura:

Para provar P → Q por contradição:
Assuma P e ¬Q.
[deduções que levam a C ∧ ¬C, uma contradição]
Contradição! Logo ¬Q é falso, portanto Q. ∎
Cuidado — contradição ou contraposição?
Se ao provar P→Q por contradição (assumindo P ∧ ¬Q) você nunca usou P, ou sua contradição veio apenas de algo relacionado a ¬Q, então você fez uma contraposição. Reescreva — será mais clara.

Exemplo — √2 é irracional:

Teorema: √2 ∉ ℚ
Prova: Assuma √2 ∈ ℚ. Logo √2 = a/b com a,b ∈ ℤ, b ≠ 0, sem fator comum.
Elevando ao quadrado: a² = 2b² → a² é par → a é par → a = 2k
Substituindo: b² = 2k² → b² é par → b é par.
Contradição: a e b não podem ser ambos pares (fração irredutível). ∎

Exemplo — infinitos primos:

Teorema: Existem infinitos números primos.
Prova: Assuma que existem apenas n primos: {p₁, p₂, …, pₙ}.
Defina a = (p₁·p₂·⋯·pₙ) + 1.
• Se a é primo: contradição (a ∉ {p₁,…,pₙ}).
• Se a não é primo: algum pₖ divide a. Mas pₖ divide p₁·⋯·pₙ,
logo pₖ divide 1. Impossível. Contradição. ∎
Referência Bibliográfica
Book of Proof (Hammack): Cap. 6 (pp. 118–130) — Prova por contradição.
Verificação rápida — 1
ANa prova por contradição, assume-se ¬Q e mostra-se ¬P.
BNa prova por contradição de P → Q, assume-se P ∧ ¬Q e mostra-se que isso leva a uma impossibilidade lógica.
CNa prova por contradição, verifica-se que P → Q é falsa em algum caso.
Verificação rápida — 2: por que a contradição é especialmente útil para √2 ∉ ℚ?
APorque é a técnica mais fácil em geral.
BPorque é uma proposição não condicional — não tem forma P→Q — e a contradição é a técnica natural para esse tipo.
CPorque P → Q é muito difícil de identificar nesse teorema.
Verificação rápida — 3: você está provando P→Q por contradição e percebe que nunca usou P. Isso significa:
AA prova está errada — P deve ser usado obrigatoriamente.
BVocê fez, na verdade, uma prova por contraposição (¬Q→¬P). Reescreva assim — ficará mais simples e clara.
CA prova está correta e é mais forte por não precisar de P.
Aula 05

Prova por Indução

Caso base + passo indutivo — provar para todos os naturais de uma vez

Vídeo Aula 05 — em breve
~12 min
Indução Matemática — estrutura, validade e exemplosAULA 05
Baixar slides desta aula (PDF)

A indução resolve um problema que as outras técnicas não conseguem: provar que uma propriedade vale para todos os números naturais — infinitos casos — de uma só vez.

A ideia é como uma fileira de dominós: se o primeiro cai (caso base) e cada dominó que cai derruba o seguinte (passo indutivo), então todos cairão. Formalmente, provamos P(1) e provamos que P(n) → P(n+1) para todo n. O axioma de indução garante que P(n) vale para todo n ∈ ℕ.

Atenção ao passo indutivo: o erro mais comum é provar P(n+1) sem usar a hipótese P(n). Se você não usou P(n), a prova está incompleta — ou você encontrou uma prova direta, não uma indução.

Axioma de indução:

(P(1) ∧ (∀n ∈ ℕ)(P(n) → P(n+1))) → (∀n ∈ ℕ)P(n)

Estrutura da prova:

Teorema: ∀n ∈ ℕ, P(n)
Prova:
Base: Mostre P(1).
Passo: Assuma P(n) (hipótese de indução).
Mostre P(n+1) usando P(n).
Conclusão: Por indução, P(n) vale para todo n ∈ ℕ. ∎

Exemplo — 17ⁿ − 10ⁿ divisível por 7:

Base: n=1: 17−10 = 7. Divisível por 7. ✓
Passo: Assuma 7 | (17ⁿ−10ⁿ). Então:
17ⁿ⁺¹ − 10ⁿ⁺¹ = 17·17ⁿ − 10·10ⁿ
= (7+10)·17ⁿ − 10·10ⁿ
= 7·17ⁿ + 10·(17ⁿ−10ⁿ)
7·17ⁿ é divisível por 7 ✓
10·(17ⁿ−10ⁿ) é divisível por 7 pela H.I. ✓
Logo 7 | (17ⁿ⁺¹−10ⁿ⁺¹). ∎

Exemplo — n ímpar → n² ímpar (bidirecional):

Teorema: n é ímpar ↔ n² é ímpar
Ida (direta): n = 2a+1 → n² = 4a²+4a+1 = 2(2a²+a)+1. Ímpar. ✓
Volta (contraposição): n par → n = 2a → n² = 4a² = 2(2a²). Par. ✓ ∎
Referência Bibliográfica
Book of Proof (Hammack): Cap. 10 (pp. 162–180) — Prova por indução matemática.
Verificação rápida — 1
ANa indução, verifica-se P(n) para n = 1, 2, 3, … até um ponto razoável.
BNa indução, prova-se P(1) (caso base) e depois P(n) → P(n+1) (passo indutivo), garantindo P(n) para todo n ∈ ℕ.
CNa indução, assume-se P(n) falso e chega-se a uma contradição.
Verificação rápida — 2: no passo indutivo, o que é a "hipótese de indução"?
AA afirmação P(1) que já foi provada no caso base.
BA suposição de que P(n) é verdadeiro para um n arbitrário — que é então usada para provar P(n+1).
CA afirmação P(n+1) que queremos provar.
Verificação rápida — 3: no passo do exemplo 17ⁿ−10ⁿ, onde a hipótese de indução foi usada?
APara mostrar que 7·17ⁿ é divisível por 7.
BPara concluir que 10·(17ⁿ−10ⁿ) é divisível por 7, pois a H.I. garante que 7 | (17ⁿ−10ⁿ).
CNo caso base, quando n=1.

03múltipla escolhaQual técnica é mais adequada para provar "√2 é irracional"?▼
a)Prova direta — assume-se √2 racional e deduz-se uma propriedade.
b)Prova por contraposição — a proposição tem forma P→Q clara.
c)Prova por contradição — é uma proposição não condicional, ideal para assumir o contrário e chegar ao absurdo.

05múltipla escolhaVocê está provando P→Q por contradição (assumiu P ∧ ¬Q). Ao final, percebe que nunca usou P na sua dedução. O que isso indica?▼
a)A prova está errada — P sempre deve ser usado.
b)Você fez, na prática, uma prova por contraposição (¬Q→¬P). Reescreva assim — ficará mais simples.
c)A prova está mais forte por não depender de P.
A diferença entre contradição e contraposição está em P: na contradição, assume-se P ∧ ¬Q. Se P não foi usado, a prova é essencialmente ¬Q → ¬P — ou seja, contraposição.
06verdadeiro / falsoNa prova por indução de ∀n P(n), verificar P(1), P(2) e P(3) é suficiente para concluir que P(n) vale para todo n ∈ ℕ.▼
A afirmação acima é:
✓ Verdadeiro
✗ Falso
07múltipla escolhaRamsés quer provar que uma pirâmide de base n×n usa n(n+1)(2n+1)/6 blocos. No passo indutivo, ele assume que a fórmula vale para n e quer provar para n+1. Quantos blocos a mais uma pirâmide de base (n+1)×(n+1) tem em relação à de base n×n?▼
a)n blocos.
b)n+1 blocos.
c)(n+1)² blocos — o nível base da nova pirâmide.
d)2(n+1) blocos.
A pirâmide de base (n+1)×(n+1) é a pirâmide de base n×n com um nível novo embaixo. Esse nível tem (n+1)×(n+1) blocos.
08múltipla escolhaRaquel tenta provar "todas as pessoas são iguais" por indução: o caso base P(1) é trivialmente verdadeiro. No passo indutivo (de n para n+1 pessoas), ela retira uma pessoa, aplica a hipótese ao grupo de n e recoloca a pessoa. Onde está o erro?▼
a)O caso base P(1) está errado.
b)A hipótese de indução P(n) foi mal aplicada.
c)O passo de n=1 para n=2 falha: com 2 pessoas, os dois subgrupos de 1 pessoa não têm interseção, logo não se pode concluir que as duas são iguais.
O argumento funciona para n≥3, pois ao retirar cada pessoa o grupo restante tem ao menos 2 pessoas que se "sobrepõem". O erro está no passo n=1→n=2, onde os dois subgrupos de 1 pessoa não compartilham nenhum elemento.
09verdadeiro / falsoPara provar P ↔ Q basta provar P → Q; a volta Q → P é automática.▼
A afirmação acima é:
✓ Verdadeiro
✗ Falso
10múltipla escolhaVocê quer provar: "Se A ⊆ B, então x ∉ B → x ∉ A". Qual técnica é mais natural e elegante?▼
a)Contradição: assume-se A ⊆ B, x ∉ B e x ∈ A, e busca-se absurdo.
b)Contraposição: nega-se a conclusão (x ∈ A) e deduz-se a negação da hipótese (x ∈ B) usando A ⊆ B — direto e sem hipóteses extras.
c)Indução: prova-se para cada elemento x ∈ ℕ.
A contradição aqui assume A⊆B ∧ x∉B ∧ x∈A e chega em x∈B (contradizendo x∉B). Mas note: a hipótese extra x∉B não foi realmente necessária para o raciocínio — você basicamente provou x∈A → x∈B, que é a contraposição. Logo, a contraposição é mais direta.
